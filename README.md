# Practice Guidelines

When adding practice code:

1. Keep files focused on one concept.
2. Use meaningful variable and function names.
3. Add comments where they help explain the logic.
4. Avoid copying code without understanding it.
5. Try exercises independently before checking solutions.
6. Improve older code when a better approach is learned.
7. Keep project code separate from basic practice code.

# Collaboration Guidelines

Since this is a collaborative repository, both contributors should follow a consistent workflow.

### Before starting work

```bash
git pull
```

### Create a branch

```bash
git checkout -b feature/topic-name
```

Example:

```bash
git checkout -b feature/pandas-practice
```

### Add changes

```bash
git add .
```

### Commit changes

```bash
git commit -m "Add Pandas practice"
```

### Push the branch

```bash
git push -u origin feature/pandas-practice
```

Then create a Pull Request on GitHub and review the changes before merging.
